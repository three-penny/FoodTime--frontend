### 3.1 项目简介、Prompt 与 Vibe Coding 过程

#### 3.1.1 项目简介

FoodTime 是一个面向校园食堂场景的 B/S 架构前端项目，主要服务于学生查看食堂、档口、菜品与评价信息的日常使用链路。本人负责前端任务一与手机端显示相关工作，核心范围包括：首页 / 食堂选择页面、食堂详情页、菜品列表页、档口卡片、菜品详情页、菜品卡片展示，以及后续移动端 App 化 UI 适配。

前端技术栈沿用项目现有方案：Vue 3、JavaScript、Vite、Vue Router、Pinia、Axios、Element Plus、SCSS 与 Vitest。实现上采用“路由页面 + 业务组件 + Store + Mock/API 数据”的分层方式，页面通过 `src/router/index.js` 管理入口，通过 `src/store/useCanteenStore.js`、`src/store/useDishStore.js` 等 Store 管理食堂与菜品数据。

与本人任务相关的主要文件包括：

| 首页组件 | `src/components/home/HomeHero.vue`、`TodayRecommendationCarousel.vue`、`CanteenCarousel.vue`、`CanteenIntroGrid.vue`、`HomeRankingList.vue` |

```markdown
帮我把"北交干饭吧"这个学生食堂指南网站的 UI 完全重构。

==== 设计参照 ====
气质参照：
- 八九十年代国营食堂 / 大学校办食堂的搪瓷菜牌和墙上手写价目表
- 老式《大众菜谱》《家庭食谱》一类铅印小册子的内页
- 粮票、饭票、就餐卡的票证设计
- 早期《读者》《故事会》的版面节奏
- 日本昭和食堂手书 menu 的粗黑字标价
绝对不是：复古中国风、新中式茶饮、潮玩复古、Y2K、蒸汽波。
关键词是"印刷"和"票证"，不是"国潮"。

==== 调色板（严格执行）====
背景：米黄牛皮纸色 #EFE7D2（要带一点点泛黄，不是纯米色）
主墨色：墨黑 #1C1916（替代所有纯黑 #000）
朱红：印章红 #B8351F（用于标题、强调、印章、表头）
副红：旧报纸暗红 #8C2A1C（用于次级强调）
食堂绿：搪瓷盘绿 #2F5D3A（极少使用，只用于"营业中"标签等极个别场合）
浅底：象牙白 #F8F2E2（用于"纸张"卡片底）
仅 5 色，禁止出现任何其他色。禁止任何渐变。禁止任何彩色照片滤镜以外的彩色块。

==== 纹理与底层质感 ====
- 整个 body 必须有一层非常轻的纸张纤维纹理（用 SVG noise 或 base64 噪点 PNG 做 background-image，opacity 控制在 0.06–0.10）。
- 部分区块叠加非常浅的网点（halftone）底纹，模拟铅印套印不准的感觉。
- 朱红色块允许有轻微的"印偏"——做法是同一个红色块叠两层，一层 #B8351F 主色，一层 #8C2A1C 偏移 1–2px、opacity 0.4，制造套色错位。
- 红色文字和印章可以加 0.5px–1px 的随机抖动（用 SVG filter feTurbulence + feDisplacementMap），模拟铅字压印不均。

==== 字体（必须做对比）====
- 大标题：思源宋体 Heavy / Noto Serif SC 900，字距收紧到 -0.02em，必要时用 transform: scaleY(1.15) 做"瘦长标宋"效果，模仿老书刊大标题。
- 次级标题：思源黑体 Heavy / Noto Sans SC 900，配合方框、横线装饰。
- 正文：思源宋体 Regular，行高 1.8，模拟铅印书的呼吸感。
- 价格、数字：用等宽字体（如 JetBrains Mono 或 Roboto Mono），强制 tabular-nums，让所有价格列对齐成"价目表"。
- 印章/标签文字：思源黑体 Black，字距收紧，全部居中。
- 严禁使用任何圆体、手写体、艺术字、卡通字。

==== 版面骨架（关键，决定能不能脱离 AI 味）====
抛弃现在所有"卡片化"的设计语言。重做成"一份印刷品"：

1. 顶部刊头（masthead）：
   像旧报纸的报眼。左边粗黑横线 + 朱红"北交干饭吧"四个大字（字号要大到几乎顶到屏幕边缘），下方一行小字 slogan 用衬线斜体，再下方一道双线（粗 + 细）横贯整个版面。右上角放"第 X 期 / 2026 年春"这种期刊式信息。
   导航做成报纸目录式：横排栏目名用"｜"分隔，不要做成按钮，不要有 hover 高亮的胶囊背景。

2. 主推菜区（替代现在的"今天先看这几道"）：
   做成一份"今日菜单"印刷海报。
   - 标题"今日菜单"用反白处理：朱红整块色底 + 牛皮纸色字。
   - 菜品不用卡片，用表格：左侧菜名（宋体大字）、中间一行点点点 …………（这是关键，老菜单的标志），右侧价格（等宽字体）。
   - 每道菜下方小字一行简介，宋体 Italic。
   - 图片只在重点菜旁边出现，方框硬切，加 1px 黑色描边 + 一个小小的朱红"招牌"印章压在角上。

3. 食堂介绍区（替代现在的"去哪家，一眼判断"）：
   做成"分号介绍"——像旧书目录，编号用罗马数字 Ⅰ Ⅱ Ⅲ Ⅳ，朱红色，巨大，悬挂在段落左侧。
   每个食堂占一整行宽：左侧编号 + 食堂名 + 一句话评语（宋体），右侧一张窄长的黑白照片（用 CSS filter: grayscale(1) contrast(1.1)），照片下方用宋体小字标注"摄于 X 月"。
   食堂之间用 1px 黑色横线分隔，不用任何背景色块。

4. 详细信息区（替代现在的 4 个食堂卡片）：
   做成"票证"风格。每个食堂是一张饭票：
   - 牛皮纸底 + 1px 黑色虚线边框（border: 1px dashed #1C1916）
   - 左上角朱红印章："北苑食堂"
   - 票面信息用印刷表格排版："营业 06:00–21:00 / 人均 ￥16 / 招牌 卤煮饭"
   - 右下角朱红色"已验"或"未验"印章（用于"今日已开 / 未开"）
   - 左侧打孔效果（用 radial-gradient 做圆形镂空 + 锯齿 mask）模拟票根撕口
   - 票与票之间用一道剪刀虚线分隔，并放一个 ✂ 符号

5. 排行榜区（替代现在的"最近点得最多"）：
   做成老式销量榜单：
   - 顶部一个粗黑横幅"本月十大干饭榜"，反白朱红底。
   - 名次用大号宋体数字 01 02 03…… 朱红色，左对齐悬挂。
   - 菜名 + 食堂名 + 价格用印刷表格排版，依然用 ……… 引导线连接菜名和价格。
   - 前三名右侧加一个"★ 推荐"朱红印章。
   - 不要任何卡片背景，整个榜单就是一张纸上的一份榜。

6. 页脚：
   像版权页 / 奥付（colophon）。横线分隔，宋体小字：
   "北交干饭吧 ｜ 北京交通大学学生自办 ｜ 第 X 期 ｜ 印数：仅供参考 ｜ 2026"
   底部一行用宋体居中："—— 完 ——"
```

#### 3.1.3 Vibe Coding 过程

- 初稿阶段让 AI 生成首页、食堂详情、菜品列表、菜品详情与卡片组件，用 Mock 数据先保证页面可运行。

#### 3.1.4 AI 生成后的人工修改与存在问题

AI 生成后的主要人工修改：

- 将“看起来像 demo 的首页”调整为真实项目结构：拆分 `HomeHero`、`TodayRecommendationCarousel`、`CanteenCarousel`、`CanteenIntroGrid`、`HomeRankingList` 等组件，避免所有逻辑堆在首页文件中。
- 将首页食堂入口与路由行为修正为稳定链路：食堂卡片可以进入食堂详情或对应菜品列表，详情页和列表页能处理无效 `canteenId` 与空档口状态。
- 对推荐与排行榜数据做字段适配：从前端本地筛选逐步改为读取后端推荐 API，并在展示层补齐图片、评价短句、排名、标签等前端展示字段。
- 对 zine 风 UI 做人工筛选：减少 AI 容易生成的过度卡片化、大圆角、同质化阴影，保留纸张、贴纸、印章和栏目编号等与项目一致的视觉语言。
- 对移动端做二次压缩和兜底：底部导航替代顶部横向导航，首页卡片尺寸变稳定，详情页图片使用 `aspect-ratio`，后台表格保留横向滚动提示。
- 对行为变化补充测试：`AppHeader.spec.js` 覆盖移动端底部 Tab 与认证页隐藏逻辑；`useAutoHorizontalScroll.spec.js` 覆盖触摸设备暂停自动滚动逻辑。

开发中遇到的问题：

- 初期 AI 生成的视觉较偏“通用 food app”，与校园食堂和 zine 风格不完全匹配，需要通过更具体的风格 Prompt 多轮收敛。
- Mock 数据与后端接口字段存在差异，例如价格、评分、食堂 / 档口层级字段需要在 Store 或页面中做适配。
- 图片资源体积偏大，部分 JPG/PNG 会影响构建产物和移动端加载，后续仍建议继续压缩为 WebP。
- 移动端中贴纸、旋转、负 margin 和大字号容易导致重叠或横向溢出，因此后续改为更克制的 App 化布局。
- 移动端文档记录中仍存在部分非本次样式改造引入的测试失败，例如积分 Store 异步返回、投稿审核 API mock、部分组件缺少 active Pinia 等，需要后续单独修复。
